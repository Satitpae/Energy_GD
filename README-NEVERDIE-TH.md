# ระบบ TOU บน Neverdie — ชุดทดลอง

ชื่อเว็บทดลอง `energy.granddigital.co.th` ใช้ Hosting เดิมของบริษัท ไม่ใช้ R2 และไม่แก้เว็บไซต์หลัก

ตั้งแต่ 26 ตุลาคม 2026 ผู้ใช้อนุญาตให้ข้อมูลไซต์ `main` เป็นสาธารณะ เปิด Dashboard ได้โดยไม่กรอกโทเคน ทุกคนอ่านกราฟและดาวน์โหลดข้อมูลของไซต์นี้ได้ การส่งไฟล์ยังต้องใช้โทเคนส่งเดิม และไซต์อื่นยังไม่เปิดสาธารณะ

## โครงสร้าง

- เว็บ: `domains/energy.granddigital.co.th/public_html/` ภายในบัญชี granddig
- API: `api/index.php?action=tou-files`, `tou-file` หรือ `upload`
- ข้อมูลและโทเคนที่ใช้งานจริง: `.php/granddigital-ems-tou-private/` อยู่ที่โฟลเดอร์บัญชี นอก public_html โดย PHP เป็นเจ้าของ directory สิทธิ์ 0700 และไฟล์ตั้งค่า 0600
- สูตรอ่านและคำนวณ TOU ยังใช้ parser.mjs และ tou.mjs ต้นฉบับ
- ตัวส่งใช้ `uploader/config.neverdie.local.json` และตรวจทุก 60 วินาที ส่งเฉพาะเนื้อหาที่เปลี่ยน

## ชุดติดตั้ง

ติดตั้งออนไลน์และทดสอบแล้ววันที่ 26 ตุลาคม 2026 ดูผลใน `reports/neverdie-trial-status.md` Hosting นี้ใช้ Apache mod_php จึงต้องติดตั้งชุดเสริมจาก `tools/prepare-neverdie-bootstrap.py` หลัง ZIP แรก เพื่อให้ PHP สร้างพื้นที่ส่วนตัวเอง ตั้งค่าครั้งเดียวผ่าน HTTPS แล้วนำ `api/setup.php` ไป Trash ห้ามแก้โดยเปิดสิทธิ์ไฟล์โทเคนเป็น 644 และห้าม Reset Ownership พื้นที่ส่วนตัวที่ทำงานแล้ว

สร้างด้วย `python tools/build-neverdie.py` ได้ `.local/neverdie-trial.zip` ZIP นี้มีโทเคนส่วนตัว ต้องอัปโหลดไปยังโฟลเดอร์บัญชีผ่าน DirectAdmin เท่านั้น ห้ามวาง ZIP ไว้ใน public_html หรือเผยแพร่เป็นลิงก์สาธารณะ

ใน File Manager ให้ Upload ZIP ที่ `/` ของบัญชี แล้ว Extract ไปที่ `/` เดิม รายการใน ZIP มีเฉพาะโฟลเดอร์เว็บทดลองและ private directory ตามข้างต้น ไม่มีไฟล์เว็บหลักรวมอยู่ด้วย ลบ ZIP ไป Trash หลังติดตั้งเสร็จ

หลังติดตั้ง ตรวจ HTTPS และ API อ่านไซต์ main ต้องตอบ 200 โดยไม่ใส่โทเคน ส่วน API upload ที่ไม่ใส่โทเคนต้องตอบ 401 ก่อนส่งไฟล์ TOU ทดสอบผ่านตัวส่ง

โทเคนดูข้อมูลเดิมอยู่ใน `.local/neverdie-view-token.txt` แต่หน้าเว็บสาธารณะไม่ใช้แล้ว โทเคนส่งอยู่ใน config ของตัวส่ง ไม่ใช่รหัสผ่าน Hosting

## ขีดจำกัดชุดทดลอง

ไฟล์ละ 128 KiB พื้นที่ไฟล์ TOU รวมไม่เกิน 100 MiB และเพดาน payload ของคำขอ API สำเร็จ 400 MiB ต่อเดือน/2000 คำขอต่อวัน ตัวนับป้องกันการใช้งานของแอปเกินเพดาน แต่ **ไม่ใช่เพดานแบนด์วิดท์ทั้งบัญชี**: ไฟล์หน้าเว็บ คำขอที่ถูกปฏิเสธ HTTP headers และทราฟฟิกอื่นยังใช้แบนด์วิดท์ Hosting ต้องดูโควตารวมของเว็บบริษัทด้วย

ไฟล์เก็บฉบับล่าสุดของแต่ละ site/name ไม่เก็บ version history ไม่ลบไฟล์หน้างาน ต้นฉบับหน้างานยังเป็นข้อมูลสำรองหลัก ปฏิทินวันหยุดยังเป็น PEA 2026 ตามโค้ดต้นฉบับ ต้องเทียบรายงาน MEA ก่อนใช้ Billing จริง

## ยกเลิกชุดทดลอง

หากทดสอบไม่ผ่าน ให้นำเฉพาะ directory เว็บ energy และ granddigital-ems-tou-private ที่สร้างในรอบนี้ไป Trash แล้วลบ subdomain energy โดยไม่เลือกให้ลบไฟล์เว็บหลัก เก็บโค้ดในเครื่องไว้แก้ต่อ รายการ resource ที่สร้างบันทึกใน `.local/neverdie-install-manifest.json`


## ตัวส่ง TOU รุ่นใช้งาน

ชุดพร้อมย้ายเครื่องอยู่ใน `.local/TOU-Sender.zip` อ่านคู่มือภายในก่อนใช้ ทุก 60 วินาทีตรวจเฉพาะเดือนล่าสุดของแต่ละเครื่องและส่งเมื่อเปลี่ยน เดือนเก่าส่งซ้ำวันละครั้งตามวันที่ Windows ในรอบแรกที่โปรแกรมทำงานวันนั้น หากเน็ตหลุดจะลองรายการที่ยังส่งไม่สำเร็จในรอบถัดไป ไม่มี MySQL/Realtime

ตัวส่งที่กำลังทำงานบนเครื่องทดสอบใช้ `.local/TOU-Sender/config.local.json` และสถานะในโฟลเดอร์เดียวกัน ปุ่มเริ่ม–หยุด–สถานะอยู่ในชุดนี้ ยังไม่ติดตั้งเริ่มอัตโนมัติหลังเปิดเครื่อง


## เวลาติดต่อ Sender

รุ่น1.0.1ส่งสัญญาณเล็กทุก60วินาทีแม้ไฟล์ไม่เปลี่ยน หน้าเว็บแสดงเวลาที่เซิร์ฟเวอร์รับจริง (เวลาไทย) หากไม่ได้รับเกิน3นาทีขึ้นเตือนสีส้ม เวลาในป้ายนี้ไม่ใช่เวลาข้อมูลในTOU APIสถานะไม่เปลี่ยนเวลาเมื่อมีคนเปิดเว็บ
