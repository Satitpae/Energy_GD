# Dashboard TOU ทดลองในเครื่อง

ไฟล์ D01Oct26.tou = MEA และ D02Oct26.tou = Solar Cell เดือนตุลาคม 2026

## เปิดใช้งาน

1. ติดตั้ง Python หากยังไม่มี แล้วดับเบิลคลิก `start-dashboard.cmd`
2. เปิด http://127.0.0.1:8766/dashboard/ บนเครื่องนี้
3. เว็บตรวจรายชื่อและโหลดไฟล์ D01 / D02 ทุกเดือนจากโฟลเดอร์ `TOU File for test` ให้อัตโนมัติ กดปุ่ม MEA / Solar Cell แล้วเลือกเดือนข้อมูลได้
4. เมื่อเพิ่มหรือแก้ไขไฟล์ในโฟลเดอร์ กด “รีเฟรชไฟล์” บนหน้าเว็บเพื่ออ่านล่าสุด โดยคงเดือนเดิมที่เลือกไว้หากยังมีข้อมูล หรือโหลดหน้าเว็บใหม่เพื่อเริ่มที่เดือนล่าสุด
5. เก็บหน้าต่างโปรแกรมไว้ระหว่างใช้งาน ปิดด้วย Ctrl+C หากแจ้งว่า port ถูกใช้งานแล้ว ลองเปิดเว็บข้างต้นก่อน

Dashboard ใช้สีส้ม ขาว และเทาอ่อนตามภาพอ้างอิง เลือกดูทีละมิเตอร์ด้วยปุ่ม พร้อมกราฟ Demand และพลังงานรายวัน เลือกเป็นรายเดือนตามชื่อไฟล์ หากนำเข้าไฟล์หลายเดือน ตัวเลือกจะแสดงเฉพาะเดือนที่มีของมิเตอร์นั้น หากเปลี่ยนมิเตอร์แล้วไม่มีเดือนเดิมจะใช้เดือนล่าสุดที่มี ส่วนตารางรายงาน ข้อมูลทุก 15 นาที รายละเอียดตรวจสอบ และการนำเข้าไฟล์พับไว้ด้านล่าง ดาวน์โหลด CSV หรือ Excel ได้ ไม่มีการแก้ค่าต้นฉบับจากหน้าจอรุ่นนี้

กราฟวงกลมแสดงสัดส่วนพลังงานของ MEA และ Solar Cell ในเดือนเดียวกัน โดยใช้ยอด Energy รวมจากสูตรเดิม ต้องมีข้อมูลทั้งสองมิเตอร์และยอดรวมมากกว่าศูนย์จึงแสดงเปอร์เซ็นต์ กราฟนี้เป็นสัดส่วนของผลรวมสองมิเตอร์ ไม่ใช่พลังงานใช้สุทธิหรือผลประหยัด Solar หากช่วงข้อมูลสิ้นสุดต่างกันจะแจ้งเวลาของแต่ละไฟล์ใต้กราฟ

รายงานละเอียด: `reports/ผลตรวจ-TOU.md` และ `reports/audit.json`

## สูตรและที่มา

คัดลอก parser.mjs, tou.mjs และ excel.mjs จาก https://github.com/Satitpae/Dashboard_TOU โดยไม่เปลี่ยนตรรกะ ส่วนหน้าจอปรับใหม่ให้เรียบง่ายตามภาพอ้างอิง บันทึกต้นฉบับและ Git blob SHA ใน `reports/SOURCE.json` ไม่ได้แก้หรือ push กลับ repository

คงสูตร Energy วันแรกเริ่ม 00:15, วันต่อไป 00:00, OnPeak ขอบ 09:00–22:00, Demand ใช้ค่าสูงสุดจากไฟล์และรวมขอบเวลาตามต้นฉบับ ปฏิทินเป็น PEA 2026 ตามโค้ดเดิม ยังต้องยืนยันกับรายงาน MEA

ไฟล์จริงทั้งสองมีข้อมูลถึง 26 ตุลาคม 2026 เวลา 10:15 เท่านั้น มีค่าศูนย์ภายในช่วงข้อมูลและส่วนท้ายที่ยังไม่มีข้อมูล ผลแยกช่วงอาจรวมไม่เท่ากับ Total เมื่อบางช่องคำนวณไม่ได้ หน้าเว็บแสดงทีละมิเตอร์ ไม่คำนวณไฟฟ้าสุทธิหรือผลประหยัด Solar

## ตรวจซ้ำ

จากโฟลเดอร์นี้รัน `node --test` และ `python -m unittest discover -s tests -p test_server.py` เพื่อตรวจชุดทดสอบ และ `node tools/audit.mjs` เพื่อสร้างรายงานจากทุกเดือนในโฟลเดอร์ใหม่

ต้องเปิดผ่าน `start-dashboard.cmd` ซึ่งใช้ `local_server.py` เพื่อส่งรายการไฟล์จากโฟลเดอร์ให้ Dashboard อย่าใช้ `python -m http.server` รุ่นเดิม เพราะไม่มี API รายชื่อไฟล์ `/api/tou-files`

ยังไม่มี API, R2, ตัวส่ง Python หรือการ deploy Cloudflare ในระยะนี้ เปิดบนโทรศัพท์ผ่าน localhost ของคอมพิวเตอร์ไม่ได้ การทดสอบมือถือจริงจะทำหลังเตรียมการเข้าถึงระบบในระยะถัดไป
